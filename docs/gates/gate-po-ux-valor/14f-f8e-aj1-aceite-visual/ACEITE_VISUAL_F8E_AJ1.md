## 3. Ajustes mínimos aprovados na AJ1

A F8E-AJ1 incorporou os ajustes mínimos solicitados por Moisés:

1. reposicionamento do card **“Comece pelo cenário fixo”**;
2. alinhamento do cabeçalho **“Descrição”**;
3. formatação monetária completa no card-resumo global;
4. remoção da notação `k` no gráfico comparativo SAC x PRICE.

Após esses ajustes, o protótipo foi aprovado visualmente com louvor.

## 4. Decisão de produto

A direção visual do módulo Imóvel deixa de estar em busca exploratória.

A partir deste aceite:

- a F8E-AJ1 é a referência visual oficial;
- futuras implementações devem reproduzir fielmente este protótipo;
- a implementação React não pode reinterpretar livremente o visual;
- a implementação React não pode recriar o cockpit antigo;
- a implementação React não pode transformar a tela em híbrido/remendo visual;
- a fidelidade visual deve ser tratada como critério bloqueante.

## 5. Limites deste aceite

Este documento **não autoriza automaticamente**:

- implementação React real;
- alteração em `frontend/`;
- alteração em `backend/`;
- alteração em API;
- alteração em fórmulas financeiras;
- criação de PR de implementação;
- liberação da Sprint 5.

Este documento formaliza apenas o **aceite visual humano** do protótipo F8E-AJ1.
