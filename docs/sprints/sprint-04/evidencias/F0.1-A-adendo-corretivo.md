## 1. Correção: referência normativa "CMN 5.115/2024"

**Problema identificado:** a pesquisa (§1.2) e a decisão de thresholds (§4.1)
citavam "Resolução CMN nº 5.115/2024" como FATO e âncora do threshold 40%.
O Doc 03 §7.8 listava esta resolução com status FATO.

**Causa:** a referência foi registrada com base em pesquisa web sem verificação
em fonte primária (sítio do BCB, Diário Oficial). O número da resolução, o ano
e o conteúdo exato não foram confirmados diretamente.

**Correção aplicada:**
- `F0.1-pesquisa-diagnostico-financeiro.md` §1.2: status alterado de FATO para
  LIMITAÇÃO. Seção reescrita com declaração explícita de não-confirmação.
- `F0.1-pesquisa-diagnostico-financeiro.md` §6 (síntese): linha atualizada para
  LIMITAÇÃO.
- `F0.1-decisao-thresholds-diagnostico.md` §4.1: CMN removida das âncoras do
  threshold 40%. Threshold 40% requalificado como HEURÍSTICA EDUCACIONAL pura.
- `docs/baseline/03_Regras_de_Negocio.md` §7.3: âncora da fronteira 40% corrigida
  para HEURÍSTICA + LIMITAÇÃO sobre referência anterior.
- `docs/baseline/03_Regras_de_Negocio.md` §7.8: linha CMN substituída por entrada
  de HEURÍSTICA para threshold 40%.

**Estado após correção:** threshold 40% permanece no documento como HEURÍSTICA
EDUCACIONAL / DECISÃO DE PRODUTO. Se a resolução for confirmada com fonte primária,
pode ser reintegrada como FATO.

## 2. Correção: redação da Lei 10.820/2003

**Problema identificado:** o texto original afirmava (ou podia ser lido como)
que 30% é um "limite jurisprudencial" de aplicação geral no Brasil, quando na
verdade a Lei 10.820/2003 limita especificamente o crédito consignado em folha
de trabalhadores formais.

**Correção aplicada:**
- `F0.1-pesquisa-diagnostico-financeiro.md` §1.3: seção reescrita com separação
  explícita entre FATO (lei limita consignado) e INFERÊNCIA (extensão por analogia
  jurisprudencial). Adicionada limitação explícita: "30% NÃO é limite legal
  universal para comprometimento de renda no Brasil."
- `F0.1-decisao-thresholds-diagnostico.md` §4.1: 30% requalificado como "threshold
  educacional conservador" com declaração explícita de não ser norma universal.
- `docs/baseline/03_Regras_de_Negocio.md` §7.3: âncoras do threshold 30% reescritas
  com separação FATO/INFERÊNCIA e nota "específica para consignado, NÃO limite
  universal".

**Estado após correção:** 30% está corretamente posicionado como threshold
educacional conservador com três âncoras (empírica BCB + normativa consignado +
analogia jurisprudencial), sem reivindicação de ser norma de aplicação geral.

## 3. Correção: fórmula da sobra mensal

**Problema identificado:** `F0.1-decisao-thresholds-diagnostico.md` §3 tinha:
```
Sobra mensal = renda mensal - despesas fixas totais - dívidas mensais
```
Faltava o componente `total_despesas_variaveis`, presente no Doc 03 §7.2.

**Correção aplicada:**
- `F0.1-decisao-thresholds-diagnostico.md` §3: fórmula corrigida para:
```
Sobra mensal = renda_mensal - total_despesas_fixas - total_despesas_variaveis - total_dividas_mensais
```
Com nota de harmonização.

**Doc 03 §7.2:** já estava correto (4 termos). Não alterado.

## 4. Correção: override da sobra negativa (dois níveis)

**Decisão do PO/Camaleão:** o override deve ser dois níveis, não um único teto:
- `sobra < 0` E `reserva < 1 mês` → `saude_nivel = "critica"`
- `sobra < 0` E `reserva >= 1 mês` → `saude_nivel` máximo = `"fragil"`

**Correção aplicada:**
- `docs/baseline/03_Regras_de_Negocio.md` §7.6: seção "Override" reescrita com
  a regra dois níveis e justificativa.
- `F0.1-decisao-thresholds-diagnostico.md` §5.2: override reescrito com dois
  níveis.
- `F0.1-decisao-thresholds-diagnostico.md` §6 (DG-02): exemplo recalculado.

**Recálculo DG-02:**
- Parâmetros: renda=3000, despesas_fixas=2200, despesas_variaveis=700, dividas=500, reserva=0
- Sobra = 3000 - 2200 - 700 - 500 = -400 → negativa
- Reserva_em_meses = 0 / 2900 = 0 meses → < 1
- Override: sobra < 0 E reserva < 1 → `saude_nivel = "critica"`
- **Resultado correto: CRÍTICA** (antes: Frágil — versão F0.1 original)
